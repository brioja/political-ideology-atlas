# Backlog

Work on the ideology catalog, statements and audits that has been discussed but not started, one
file per topic so each can grow on its own. Each item says what would decide it. Add new ideas here,
not only in conversation, and move an item to `decided-against.md` when it is ruled out.

- [new-statements.md](new-statements.md): candidate statements and how they are chosen (low priority)
- [catalog.md](catalog.md): which ideologies the catalog includes
- [ideology-candidates.md](ideology-candidates.md): ideologies not yet in the catalog that a source turned up
- [audits.md](audits.md): audit passes and reviews not yet run
- [blocked-sources.md](blocked-sources.md): audits held back by sources we couldn't reach, for a retry
- [results.md](results.md): results page ideas (uncertainty display, parked; error bars; far-edge distance, parked)
- [decided-against.md](decided-against.md): ideas ruled out, so they aren't proposed again
